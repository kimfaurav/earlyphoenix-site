What changed

The words were already right, so none of them were rewritten for meaning.

  • Earthmark is the sender

    The real wordmark and the real palette, both taken from the live site rather than rebuilt. The dark green masthead means nobody has to read a word to know who sent it.

  • The peer comparison is a picture

    NEXT above, DFS highlighted, John Lewis and Wayfair below. Position reads at a glance instead of being inferred from three paragraphs of prose.

  • The VoucherCodes gap is now the headline of that section

    Live for all three peers, not live for DFS, in one strip. It was the sharpest commercial fact on the page and it was buried.

  • One CTA, not two

    Adding a data point is not a click, so it is described rather than buttoned. Book a call is the only button, and it points at your Calendly.

  • Every brand value lives in one file

    Watches of Switzerland is a copy of one JSON file with the figures changed. Nobody opens the markup again.

Before it can send

Four things, all on your side.

  1. Host two images

    The logo and the sector chart need a Cloudflare URL. Nothing renders until they have one.

  2. Add an unsubscribe link

    A commercial email to a business list needs one that works.

  3. Add a postal address

    The footer currently says only Earthmark.

  4. Test in a real client

    This is built to the Outlook and Gmail rules, tables, inline CSS, VML buttons, no flexbox. It has not been through Litmus. Worth one pass before the first send.

One open question

Competitor logos are supported but switched off. Gmail and Outlook block remote images by default, so a comparison carried by logos collapses to alt text for a good share of readers, and names set in type always render. Say the word and they go on, it is one line per peer.

Every figure comes from Earthmark data exactly as it appeared in your version. The sector chart is your own, recoloured to the palette, with no points moved. Built as a 34 KB email, tables and inline CSS throughout, well under the size at which Gmail clips a message.
